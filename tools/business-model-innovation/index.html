吕博士·可持续商业工具

可持续商业模式创新

从现有模式出发，设计可检验的价值主张、价值交换、循环路径和试点。

《可持续商业战略与实践》第66–75页方法与案例预览
它要回答的管理问题

现有价值主张和盈利逻辑如何同时创造经济、社会与环境价值？

解决什么企业问题

企业希望在创造商业回报的同时，解决明确的社会或环境问题，并需要重新设计产品服务、客户关系、资源组织或合作方式时，使用本 Skill 形成可检验的可持续商业模式方案。

它帮助企业从现有模式出发，判断客户真正需要什么价值、企业与伙伴分别投入和获得什么、资源怎样更有效循环，以及一项新模式适合先怎样试行。

用到哪些吕博士思想、模型和框架

本 Skill 采用吕博士可持续商业思想库的传统商业模式向可持续商业模式迁移框架与 SBM-I 创新模型，方法依据《可持续商业战略与实践》第66–75页。

  • 传统商业模式向可持续商业模式迁移框架：从经济、社会、环境三重空间，价值主张，循环设计，利益相关方网络，生态资源链接和复合价值目标六个方面，分析现有模式和新的可能性。
  • 利益相关方价值交换分析：逐一说明客户、企业、员工、供应商、合作伙伴等相关方获得什么价值、贡献什么资源或能力、承担什么成本或影响，以及价值怎样创造、传递和分配。
  • SBM-I 创新模型：以诊断、模式、检验、规模、文化五个阶段，推进从模式问题识别到试点、复制条件和组织固化的分析。

这些方法让企业同时看到商业可行性、社会环境价值和持续运行条件，并把需要验证的内容放入可控的试点安排。

如何进行分析

客户先上传现有产品服务、客户需求与反馈、订单或工单、成本与资源使用、质量与售后、供应商和伙伴协同等材料。Skill 先梳理现有商业模式的价值主张、交付方式、收入与成本、相关方关系和资源流动。

随后，Skill 依据六个模式迁移方面，提出候选的价值主张、价值交换和循环路径，并以 SBM-I 的诊断、模式、检验、规模、文化顺序设计试点。客户需求、投入成本、伙伴参与和实际效果等会影响模式成败的关键事实，作为试点核验重点；关键范围差异由 Agent 在生成报告前向客户提出具体问题。

试点产生连续记录后，企业依据客户反馈、运行情况、成本和资源使用等信息，决定继续、调整、缩小或扩大应用范围。

根据材料可能形成哪些报告内容

  • 现有商业模式的主要问题与可利用基础
  • 候选价值主张，以及客户、企业和伙伴的价值交换
  • 产品、服务、材料或资源的循环路径
  • 候选商业模式原型及其适用范围
  • 试点需要核验的关键假设、记录方式和判断条件
  • 规模化的资源、协作、风险和持续运行条件

建议准备哪些材料

  • 产品或服务说明、客户类型、价格或收费方式、订单与交付资料
  • 客户需求、使用场景、客户反馈、售后、质量或工单记录
  • 销售、采购、生产、交付、服务和成本相关的流程及记录
  • 原材料、替换件、包装、能源、废弃物或其他资源使用记录
  • 供应商、服务商、渠道伙伴及其他合作关系资料
  • 现有战略方向、试点资源、预算、人员安排和风险处理记录

客户先上传已有材料即可。Skill 根据候选模式和拟作出的决定，列出与试点判断直接相关的补充信息。

适用范围与后续 Skill 的衔接

本 Skill 用于重构商业模式和设计试点，帮助企业形成能同时创造商业、社会和环境价值的候选方案。

企业还在选择公司层面的战略方向和重大议题时，可先使用“可持续商业战略设计”。候选模式确定后，需要进入职责、行动、指标和持续复核时，可衔接“可持续商业战略实施”；需要把流程、数据、披露和持续改善连接为长期管理基础时，可衔接“可持续商业管理体系建设”。

资料来源与分析方式

分析可以依据企业提供的材料，也可以结合可核查的公开资料。

企业材料版

使用资料
根据客户提供的文件、图片、表格等材料分析，并在报告中说明所依据的材料。
适合谁使用
客户已有内部资料，希望用自己的智能助手整理问题并形成报告。
材料差异如何处理
材料存在关键差异时，先请客户确认；待补充的信息在报告中说明。

公开资料版

使用资料
可结合可核查的公开资料分析，并记录资料来源和检索日期。
适合谁使用
客户希望在已有材料之外，结合企业公开信息开展分析。
材料差异如何处理
公开资料与客户材料存在关键差异时，先请客户确认；报告说明采用的依据。

客户如何使用

提供材料

客户通过自己的智能助手提供现有产品、客户反馈、成本、资源、交付和伙伴资料。

查看结果

客户查看候选模式与试点核验条件，依据实际反馈决定继续、调整或扩大范围。
