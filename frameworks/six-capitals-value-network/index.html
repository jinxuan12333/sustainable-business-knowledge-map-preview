  1. 自然资本

    企业运营依赖并影响的能源、水、空气、原材料、碳汇和生态系统服务。管理重点是从单向消耗转向保护、恢复和增值，并把生态变化连接到经营风险与价值。

    可持续商业六大资本价值网络模型，2026，第四章4.1 · 自然资本
  2. 物质资本

    厂房、设备、生产线、物流设施、包装和其他承载经营活动的物理基础。管理重点是通过低碳化、循环化和效率改善延长使用价值、减少环境足迹。

    可持续商业六大资本价值网络模型，2026，第四章4.1 · 物质资本
  3. 人力资本

    员工、管理者和合作伙伴所拥有的知识、技能、判断、学习与创新能力。它负责把战略转成行动，并激活其他资本的潜力。

    可持续商业六大资本价值网络模型，2026，第四章4.1 · 人力资本
  4. 财务资本

    支持转型投入、经营周转和价值核算的资金及财务结果，包括绿色融资、专项预算和可持续相关收益。其作用是支撑协同，而非成为唯一价值尺度。

    可持续商业六大资本价值网络模型，2026，第四章4.1 · 财务资本
  5. 商业—社会生态资本

    由客户信任、社会信任、品牌影响、供应链协同、行业联盟、渠道网络和共同标准形成的关系与生态能力。它把企业内部价值连接到价值链和社会。

    可持续商业六大资本价值网络模型，2026，第四章4.1 · 商业—社会生态资本
  6. 数智资本

    由可治理的数据、算法、知识、数字平台、智能体、专利和技术系统形成的能力与资产。它使价值创造和传递过程能够被连接、追溯、衡量与改进。
